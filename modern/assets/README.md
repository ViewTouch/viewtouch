# Assets

Files the modern ViewTouch builds into the program (as Qt resources):

- `fonts/` – DejaVu Sans and Sans Bold (https://dejavu-fonts.github.io), under the free DejaVu / Bitstream Vera font license, which allows embedding and redistribution.
- `textures/` – the classic ViewTouch button textures (XPM), from ViewTouch itself (GPL, see LICENSE).
- `images/burger.png` – a sample menu picture, from ViewTouch itself.
